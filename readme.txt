uxnclojure
==========

UXN/Varvara written in Clojure.

I don't know what the hell I'm doing here. I just
wanted to write my own fantasy console in Common
Lisp and figured to learn a new language to expand
my horizon, even though I still think CL is much more
beautiful and elegant, but I want to know what else 
there is in the land of Lisp (or rather Lisp-alikes).
Also learn how to write a proper fantasy console, so
I might implement Varvara/UXN before I start making 
my own project.
